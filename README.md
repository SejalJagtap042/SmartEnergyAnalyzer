# Smart Energy Analyzer

A Java-based Smart Energy Consumption Analyzer that helps users monitor electricity usage, estimate bills, and receive energy-saving suggestions.

## Features

- View appliance information
- Calculate total energy consumption (kWh)
- Predict electricity bill
- Smart energy-saving suggestions
- Menu-driven console interface
- Modular Java project structure

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- IntelliJ IDEA
- Git & GitHub

## Project Structure

src/
├── database/
├── model/
├── service/
├── ui/
└── Main.java
